# /analyze — 분석 코드 생성

분석 설계서를 기반으로 실행 가능한 Python 분석 코드를 생성합니다.

## 실행 흐름

### 1단계: 정보 수집
AskUserQuestion을 사용하여 확인:

1. **분석 설계서가 있나요?** (파일 경로 — /design 결과물)
2. **코드 구조를 어떻게 잡을까요?**
   - **가설 단위**: 가설별로 추출→가공→분석→시각화→요약
   - **프로세스 단위**: Data Extraction → Preprocessing → Definition → Execute → Visualization → Summary
3. **데이터는 이미 추출되어 있나요?** (DataFrame 변수명 등)
4. **출력 형식**: .py 파일 (기본) 또는 .ipynb
5. **파일 저장 경로**

### 2단계: 기존 코드 확인
프로젝트 내 기존 코드 패턴 확인:
- 유틸 함수 로드 방식
- import 패턴, 변수 명명 규칙

### 3단계: 코드 생성
`code-generator` 에이전트를 호출:

```
Agent(subagent_type="code-generator", prompt="[설계서 내용 + 구조 선호 + 기존 코드 패턴]")
```

코드에 반드시 포함:
- 환경 설정 (import, 한글 폰트, 유틸 로드)
- 셀 구분 (`# %%`, `# %% [markdown]`)
- 각 분석 블록 후 **마크다운 셀** (가설, 지표 정의, 계산 방법, 해석)
- 중간 검증 코드 (shape, null 체크)

### 4단계: 코드 리뷰 및 확인
- 생성된 코드를 **블록 단위로** 사용자에게 보여주고 확인
- 수정 요청 반영 후 최종 파일 저장

### 5단계: 후속 안내
- **시각화 추가/수정** → `/viz`
- **결과 해석** → `/interpret`
- **보고서 작성** → `/report`

## 주의사항
- 분석 설계서의 **지표 수식을 정확히** 코드로 변환.
- 사용자의 **기존 유틸 함수를 우선** 사용 (execute_query 등).
- 매직넘버 사용 금지 — 분석 기간, 기준값 등은 **변수로 정의**.
- 각 셀은 **독립적으로 실행 가능**하도록 작성.
