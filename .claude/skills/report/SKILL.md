# /report — 보고서 초안 생성

분석 결과를 바탕으로 노션에 붙여넣을 수 있는 마크다운 형식의 보고서 초안을 생성합니다.

## 실행 전 필수

**반드시 `references/report-template.md`를 읽고** 보고서 구조를 확인한 후 작업을 시작하세요.

## 실행 흐름

### 1단계: 정보 수집
AskUserQuestion을 사용하여 확인:

1. **분석 코드 파일 경로** (.ipynb 또는 .py — 마크다운 셀의 결과 요약 활용)
2. **결과 해석이 있나요?** (/interpret 결과가 있으면 경로 확인)
3. **보고 대상은 누구인가요?**
   - 경영진 → 수치 중심, 결론 먼저, 기술 디테일 최소화
   - 기획팀 → 가설 검증 중심, 기능 개선 방향 강조
   - 전체 공유 → 배경 설명 상세, 접근성 높게
4. **특별히 강조하고 싶은 포인트가 있나요?**

### 2단계: 보고서 초안 생성
`report-writer` 에이전트를 호출:

```
Agent(subagent_type="report-writer", prompt="[분석 결과 + 해석 + 보고 대상 + 강조 포인트 + report-template.md 내용]")
```

### 3단계: 초안 검토 및 수정
- **섹션별로** 사용자에게 보여주고 피드백 수집
- 톤, 강조점, 추가 내용 등 수정사항 반영
- 그래프 삽입 위치: `[📊 그래프: {설명} — 파일: {파일명}]` 플레이스홀더

### 4단계: 최종 파일 저장
- 최종 보고서를 .md 파일로 저장
- 사용자가 노션에 복사-붙여넣기하여 사용

## 주의사항
- 분석 코드의 **마크다운 셀 내용을 적극 활용**.
- 보고서 수치와 분석 결과 수치가 **정확히 일치**하는지 확인.
- 그래프는 직접 삽입하지 않음. **플레이스홀더로 위치만 표시**.
