## 톤 조정 가이드

| 보고 대상 | 톤 | 디테일 수준 |
|----------|-----|-----------|
| 경영진 | 수치 중심, 결론 먼저 | 기술 디테일 최소화 |
| 기획팀 | 가설 검증 중심 | 기능 개선 방향 강조 |
| 전체 공유 | 배경 설명 상세 | 접근성 높게 |

## 수치 표현 규칙

- 퍼센트: 소수점 2자리 (예: 23.52%)
- 큰 수: 천 단위 구분 (예: 1,234,567)
- 변화율: 부호 포함 (예: +15.2%, -3.8%)

## 그래프 플레이스홀더 형식

```
[📊 그래프: {차트 설명} — 파일: {파일명}]
```

사용자가 노트북에서 실행한 그래프 이미지를 이 위치에 삽입.
